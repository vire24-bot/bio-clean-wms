## Información de la Empresa
* **Nombre:** Bio-Clean
* **Descripción:** Empresa dedicada a la distribución y gestión de productos químicos e insumos de limpieza industrial.
* **Aplicación Objetivo:** Sistema WMS (Warehouse Management System) enfocado en el control de inventario, registro de entradas/salidas de productos y seguimiento de stock en tiempo real.

---

## Mapa de Capacidades
1. **Gestión de Inventario y Productos:** Registro, edición, eliminación y alertas de bajo stock para insumos químicos.
2. **Gestión de Entradas y Salidas:** Registro de lotes, proveedores y despacho de materiales.
3. **Control de Usuarios y Permisos:** Autenticación y asignación de roles para administradores y operadores de bodega.
4. **Reportes e Históricos:** Monitoreo de movimientos de almacén en tiempo real para auditoría.

---

## Tecnologías Utilizadas
* **Back-End:** Java 17+, Spring Boot
* **Front-End:** React.js / Next.js
* **Base de Datos:** PostgreSQL / MySQL
